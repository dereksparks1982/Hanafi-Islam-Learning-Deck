# 99 Names of Allah Expansion — v1.4 R3

A 12-card expansion for studying the traditional enumeration of the 99 Names of Allah.

- **Card 1:** expansion guide and source note
- **Cards 2–12:** nine Names per card, for all 99 Names
- Arabic, transliteration, and concise English study meanings
- low-ink v1.4 header treatment with consistent titles and separator line

The authentic core hadith concerning ninety-nine Names is distinguished from the traditional explicit enumeration used for this study set. See `SOURCE_NOTES.md` for the sourcing note.
