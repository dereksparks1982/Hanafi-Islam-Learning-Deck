# Arabic Alphabet Expansion — Hanafi Learning Deck v1.5

A 28-card Arabic alphabet and pronunciation expansion for the Hanafi Learning Deck.

Each card uses the approved low-ink printable format and includes:

- the Arabic letter and name
- transliteration
- plain-English pronunciation guidance
- mouth and articulation instructions
- voiced/voiceless and light/heavy guidance
- common pronunciation mistakes to avoid
- isolated/initial/medial/final forms, with non-joining forms marked clearly
- a simple example word with transliteration and English meaning
- concise study notes

## Contents

- `cards/` — 28 individual 1000×1400 PNG cards
- `sheets/` — 7 four-card printable sheets
- `contact_sheet.png` — visual overview
- `MANIFEST.txt` — file list, sizes, and SHA-256 hashes
- `SOURCE_NOTES.md` — pronunciation and orthography notes

The expansion is independently numbered from 1–28.
