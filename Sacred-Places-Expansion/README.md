# Sacred Places Expansion — Version 1.2

This expansion is separate from the base Hanafi Learning Deck.

- Base deck remains Cards 1–145 in `cards/`.
- This expansion contains Cards 146–164 only.
- Card 146 is the Sacred Places color key.
- Cards 147–164 are Sacred Places location cards.
- Cards retain the deck-wide numbering so expansion packs can be combined without renumbering.
- Card format: 1000 × 1400 pixels, 5:7 playing-card proportion.
- Cards 147–164 use the accepted large photographic image layout with a lower information section.

## Expansion policy

Every expansion pack remains in its own top-level folder and its own downloadable package. Expansion cards are never added to the base `cards/` folder.
