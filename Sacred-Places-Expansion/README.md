# Sacred Places Expansion — v1.4 R2

This expansion remains separate from the Hanafi Learning Deck main deck.

## Numbering

- Sacred Places is independently numbered **1–19**.
- Card 1 is the expansion color key.
- Cards 2–19 are the approved Sacred Places location cards.
- Historical v1.2 copies used numbers 146–164. Those numbers are obsolete for the current expansion.
- Future additions append to the end of this expansion without renumbering the main deck or other expansions.

## Visual standard

- 1000 × 1400 px, 5:7 proportion.
- Approved large photographic imagery is retained.
- v1.4 continuous category-colored rounded frame and inner accent line.
- Lowered v1.4 title placement.
- Expansion color identifies site type; it is not a ranking of sanctity.
