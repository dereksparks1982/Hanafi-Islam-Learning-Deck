# Optional Card Back

This folder contains the **optional decorative card back** for the Hanafi Learning Deck.

- `CardBack.png` is the printable back design.
- It is **not part of the numbered main deck or any numbered expansion**.
- Learners may print the study cards single-sided and ignore this folder completely.
- Anyone who wants a finished two-sided physical deck may print this design on the reverse of the cards.

The card back is provided as an optional add-on only.
