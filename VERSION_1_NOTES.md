# Hanafi Learning Deck — Version 1.0

Version 1.0 is the first public baseline of the Hanafi Learning Deck.

## Highlights

- 145 study cards
- introductory card explaining what the Hanafi school is
- Hanafi prayer, purification, duʿā, travel, illness, Janazah, special-prayer, protection, and daily-life material
- Arabic text, transliteration, English meaning, rulings, notes, and sources where appropriate
- selected reflection material only on cards with genuine spare room
- consistent large card headers, with long titles wrapping instead of shrinking
- corrected two-column label spacing on prayer-map, timing, travel, and similar cards
- unsupported-glyph cleanup
- improved use of vertical space without enlarging body text
- accent bars end cleanly where the rounded card border begins curving
- no stick-figure prayer diagrams; physical movements are described in words
- 37 printable four-card sheets

## Review Status

This is a **Hanafi study aid, pending imam review**.

If an imam or qualified Hanafi scholar finds an error, please report:

1. the card number
2. the exact current wording
3. the exact correction
4. the source or explanation, when available

The purpose of the project is practical learning. Corrections are welcome because the goal is to make the deck more accurate and useful over time.
